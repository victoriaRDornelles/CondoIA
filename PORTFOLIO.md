# CondoIA — Projeto de Portfólio

## Descrição

O **CondoIA** é um sistema web para gestão operacional de condomínios, desenvolvido com Python, Flask e SQLite.

A aplicação centraliza rotinas de manutenção, rondas, ocorrências, documentos e acompanhamento de indicadores.

## Destaques técnicos

- Backend em Python/Flask
- API HTTP organizada por módulos funcionais
- Banco relacional SQLite
- Autenticação e autorização por perfis
- Sessões com tokens protegidos por hash
- Auditoria das operações
- Histórico de ordens de serviço protegido contra alteração/exclusão
- QR Codes para validação de rondas
- Upload e validação de imagens/documentos
- Dashboard e relatórios
- Testes automatizados
- Módulo de assistência por IA

## Tecnologias

**Python · Flask · SQLite · JavaScript · HTML · CSS · Pillow · QR Code · IA**

## Como apresentar

Uma demonstração pode ser iniciada com:

```bash
python manage.py demo
python app.py --demo
```

O modo demo cria dados fictícios separados do banco de desenvolvimento, permitindo apresentar o sistema sem utilizar informações reais.

## Descrição curta para currículo

> Desenvolvimento de sistema web em Python/Flask para gestão condominial, com autenticação por perfis, banco SQLite, ordens de serviço, rondas com validação por QR Code, ocorrências, uploads seguros, auditoria, dashboard, testes automatizados e módulo de IA.

Este projeto reúne conceitos de desenvolvimento de software, banco de dados, segurança, APIs, frontend, testes e automação em uma aplicação funcional orientada a regras de negócio.
